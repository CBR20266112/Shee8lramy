## 🔥 핵심 주요 기능

### 1. 🚨 Web Audio API 기반 괴악한 기상 알람 센터 (`/pages/wake.html`)
- 외부 오디오 파일 없이 `sound.js`에서 오실레이터와 노이즈 필터로 실시간 오디오 합성 재생:
  - 🚨 **비상 공습 사이렌**: 300Hz ~ 1200Hz 주파수 스윕 + 고출력 펄스 변조
  - 🪚 **칠판 긁는 소리 & 비명**: 3.5kHz ~ 6kHz 고주파 밴드패스 필터링
  - 🐔 **시끄러운 미친 수닭**: 하모닉 오실레이터 스윕 + 비브라토
  - 📢 **교관 긴급 점호 비상벨**: 240BPM 880Hz 고출력 사각파 타격
- **강제 기상 3대 해제 미션**:
  1) `전공 상식 퀴즈`: 랜덤 학사/전공 문제 정답 입력
  2) `타자 타이핑`: "교수님 지각 죄송합니다" 100% 정타 입력
  3) `광란의 화면 연타`: 15초 내 30회 연타 완료 시 알람 해제

### 2. 📅 카카오톡 스타일 자연어 캘린더 파서 (`/pages/calendar.html`)
- *"내일 오후 2시 공학관 302호 데이터베이스 과제 제출"* 등 공지/과제 줄글 입력 시 정규식 NLP 파서 작동
- 날짜, 시간, 장소, 과제명 자동 파싱 및 스케줄 카드 즉시 생성
- 과제 D-Day 및 주간 출결 카운트다운 연동

### 3. 👥 학점 방어 친구 공동체 (`/pages/friends.html`)
- **실시간 기상/출결 현황판**: `생존(기상완료)`, `위험(알람중)`, `전사(지각확정)` 3가지 실시간 상태 및 ⚡ 모닝 꿀밤(찌르기) 기능
- **시간표 오버레이**: 친구와 겹치는 공강 시간 자동 탐색 및 공강 메이트 매칭
- **연동 상태 참고**: 현재 체크아웃의 `js/friends.js`는 `DUMMY_FRIENDS` 데이터를 반환합니다. 따라서 UI와 시나리오가 실시간 공동체를 지향하더라도 실제 계정 간 실시간 동기화는 이 코드만으로 확인되지 않습니다.

### 4. 🐑 학점/출결 연동 다마고치 마스코트 '쉽라미' (`index.html`)
- 기상 미션 및 출석 달성도에 따라 성장 및 포즈 변화하는 대학생 전용 학점 방어 다마고치 마스코트 **'쉽라미'**
- **캐릭터 톤**: 귀여운 양의 외모와 반대로 성질머리 더럽고 까칠한 쉽라미가 대학생과 현대인을 다정한 응원보다 잔소리와 닦달로 재촉하는 코믹한 캐릭터입니다. 악의나 실제 위해가 아니라 정감 있는 투덜거림과 과장된 핀잔이 핵심입니다.
- **코드에서 보이는 근거**: `js/mascot-ai.js`는 자신을 “학사 일정 감시 팩폭 엔진”과 “츤데레 팩폭 대답”으로 설명하고 발표·과제·시험·수업·공강별 잔소리를 둡니다. `index.html`의 홈 대사에도 “일어나...”와 “뛰어!!” 같은 재촉이 있습니다. 과제 대사의 “털 다 뽑아버린다”처럼 센 문구는 캐릭터의 과장된 양털 개그로 쓰였지만, 사용자에게 악의적 위협으로 들리지 않도록 표현 강도를 살피는 것이 톤의 기준입니다.

## 💤 함께 제공되는 수면·힐링 기능

대학생 출결·학사 관리가 현재 README의 중심 방향이며, 코드에는 기존 Sleepy Sheep 경험에서 이어진 기능도 포함되어 있습니다.

## 🧩 기술 및 저장 방식 (현재 소스 기준)

- 정적 HTML/CSS와 JavaScript ES Modules 구조이며, `pages/`, `js/`, `css/`, `assets/`에 화면·모듈·스타일·이미지가 나뉘어 있습니다.
- 설정, 양 상태, 수면 및 앱 기능 데이터는 브라우저 `localStorage`에 저장됩니다. 별도 서버 동기화가 확인되지 않는 데이터는 브라우저/기기 간 공유되지 않으며 브라우저 저장소를 지우면 손실될 수 있습니다.
- `manifest.webmanifest`, `sw.js` 및 알람·설치 관련 코드가 있습니다. PWA 설치와 알림·알람의 실제 동작은 브라우저 권한과 실행 환경에 따라 달라질 수 있습니다.
- 소스 버전은 `VERSION`과 `js/constants.js`의 `APP_VERSION`에 기록되어 있습니다. 현재 체크아웃에서 확인한 값은 `1.96.1`입니다.

## 💻 로컬 개발 및 데모 실행

1. 저장소 클론:
   ```bash
   git clone https://github.com/CBR20266112/Shee8lramy.git
   cd Shee8lramy
   ```
2. 로컬 실행:
   - **Windows**: `serve-demo.bat` 실행
   - **Linux / macOS**: `chmod +x serve-demo.sh && ./serve-demo.sh`
3. 브라우저 접속: `http://localhost:8000`

위 실행 방법은 저장소에 포함된 스크립트 기준입니다. 이 문서 수정 과정에서 현재 GitHub Pages 배포 상태나 브라우저 런타임은 재검증하지 않았습니다. 문서별 날짜와 검증 범위는 [`docs/README.md`](docs/README.md)를 참고하세요.
